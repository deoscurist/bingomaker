# BingoMaker

Create your own bingo cards, play along, and revisit your results.

Turn a movie night, a meeting, or an everyday challenge into a game: add things you expect to happen and mark them as you go.

## What you can do

- Create and edit bingo cards with up to 25 items.
- Mark and unmark cells during a game.
- Keep track of how long you’ve been playing.
- Mark items and finish a game from the system tray.
- Browse previous games and view their saved boards.
- See how many times you’ve played each card.
- Delete cards and game results you no longer need.

Your cards and game results are saved on your device.

## Getting started

1. Create a card, give it a name, and add your items.
2. Select the card to start a game.
3. Mark an item whenever it happens.
4. Finish the game to save your results.

To revisit a game, open the card’s statistics and select a saved session.

## Development status

BingoMaker is still in development. The interface and available features may change.
